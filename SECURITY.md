# Security Policy

At NexusAI, we take the security of our enterprise RAG workspace seriously. We appreciate the efforts of security researchers and community members who assist us in maintaining high security standards.

---

## 🛡️ Supported Versions

We actively issue security updates and patches for the following versions of NexusAI:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 📩 Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have discovered a security vulnerability in NexusAI, please report it privately:

1. Email your findings to **[security@nexusai.dev](mailto:security@nexusai.dev)**.
2. Include a detailed description of the vulnerability and steps to reproduce (proof of concept code, requests, or screenshots).
3. Specify the affected component (e.g., Frontend, FastAPI Backend, LangChain pipeline, FAISS index access, Auth session handling).

---

## ⏱️ Response Timeline & Expectations

When you submit a vulnerability report to `security@nexusai.dev`, you can expect:

- **Initial Acknowledgment:** Within **24 to 48 hours** confirming receipt of your report.
- **Triage & Assessment:** Within **5 business days** providing an initial evaluation and severity assessment.
- **Remediation & Patching:** High-severity vulnerabilities will be prioritized for patching within **14 business days**.
- **Public Disclosure:** Once fixed, a security release will be published along with appropriate credit to the reporter (if desired).

---

## 🔒 Responsible Disclosure Policy

We ask that all security researchers adhere to the following responsible disclosure guidelines:

- **Confidentiality:** Keep any information regarding the vulnerability confidential until we have had reasonable time to release a patch.
- **Data Protection:** Do not access, modify, or destroy user data or system configurations during testing.
- **Non-Disruptive Testing:** Avoid performing Denial of Service (DoS) attacks, spamming, or automated high-volume scans that degrade performance for other users.
- **Good Faith:** Act in good faith to avoid privacy violations, destruction of data, and interruption or degradation of our services.

Thank you for helping keep NexusAI secure! 🚀
